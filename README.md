# 📊 Sales Data Analysis Using Excel

## 📌 Project Description
This project focuses on analyzing sales data using Microsoft Excel. 
The main objective is to understand sales performance, identify trends, and generate meaningful insights for decision-making.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Graphs
- Excel Formulas
- Data Cleaning Techniques

## 📂 Dataset
The dataset contains sales-related information such as:
- Product Name
- Category
- Sales Amount
- Quantity
- Region
- Date

The data has been cleaned and processed before analysis.

## 📈 Key Features
- Data cleaning and formatting
- Monthly and yearly sales analysis
- Product-wise performance evaluation
- Region-wise sales comparison
- Dashboard and visualization creation
- Profit and revenue calculation

## 📊 Analysis Performed
- Total Sales Calculation
- Average Sales Analysis
- Trend Analysis
- Top Performing Products
- Low Performing Areas Identification

## 🎯 Results & Conclusion
- Identified top-selling products
- Found high-performing regions
- Observed seasonal sales trends
- Improved data accuracy through cleaning

This analysis helps in making better business and marketing decisions.

## 🚀 How to Use
1. Download the Excel files from this repository
2. Open in Microsoft Excel
3. Explore Pivot Tables and Dashboards
4. Modify data to perform further analysis
